# Hobbit-platform

A Hobbit/Lord of the Rings themed interactive game platform in Hungarian. Features race selection, 15 quest-type challenges, a board game, and Firebase-backed multiplayer.

## Language

language: hu

## Tech Stack

- **Frontend:** React 18 + Vite 6
- **Backend/DB:** Firebase Realtime Database
- **Hosting:** GitHub Pages (via GitHub Actions)
- **Package Manager:** npm

## Installed Skills

- blox-skills (full suite)

## Conventions

- All user-facing text is in Hungarian
- CSS-in-JS via template literals (inline styles + CSS strings)
- Single-file component architecture (large JSX files)
- Firebase config via environment variables (.env)
- No TypeScript (plain JSX)

## Commands

- `npm run dev` — start dev server
- `npm run build` — production build
- `npm run preview` — preview production build
